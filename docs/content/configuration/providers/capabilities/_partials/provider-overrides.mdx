Capability overrides are added manually inside a provider entry under `capabilities.<capability-id>`.
Identica does not create these nested override blocks automatically just because a provider supports a capability.

If you want provider-specific behavior, add the capability block yourself.
If you leave the block out, the capability continues to use its shared settings.
If you add only some fields, only those fields are overridden and the rest continue using the shared capability configuration.

Basic shape:

```yaml
providers:
  - id: "your-provider-id"
    capabilities:
      your_capability_id:
        someField: value
```
