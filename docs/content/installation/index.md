# Installation

Identica installation is split into two operator paths:

- [Normal installation](./normal/index.md) for a standard setup without replication
- [Advanced installation](./advanced/index.md) for Redis-backed replicated state, restart continuity, and custom server routing

## Artifacts

For now, Identica artifacts are distributed through [GitHub releases](https://github.com/whereareiam/Identica/releases).
Later, this documentation can also point to Modrinth resources, with one resource per artifact, without changing the installation flow itself.

## Provider scope

The installation walkthroughs in this section only cover the official `Cracked` and `Premium` providers.
That is a documentation scope choice, not a product limit.

Identica is provider-oriented, so official and unofficial providers can be added over time.
Use the [Providers overview](../providers/index.md), [Official providers](../providers/official/index.md), and [Community providers](../providers/community/index.md) pages to discover broader provider options.

## Platforms

Both installation guides start with a `Platform` block.
Today that block documents `Velocity`.
When new platforms are added, the same structure can be extended without rewriting the rest of the installation information.
