---
title: Join Restriction
description: Provider-scoped configuration for the typed join restriction module.
---

The `join` typed restriction module is installed under the generic `restriction` capability.
It controls whether a provider may temporarily restrict new joins through the admin restriction commands.

Join restriction provider overrides live under `providers[].capabilities.restriction.join`.

## Provider Overrides

### capabilities.restriction.join.enabled

<Badge type="warning">Advanced</Badge>

- Takes: `true` or `false`
- Current default: `false`
- Affects: whether this provider exposes the typed join restriction runtime
### capabilities.restriction.join.allow

<Badge type="warning">Advanced</Badge>

- Takes: a list of signal ids
- Current default: absent unless explicitly configured
- Affects: which contributed join signals may allow the provider while join restriction is active
